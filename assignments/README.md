## What's Inside Each Module

### 🐍 Module 1 — Selenium Automation
Six hands-on assignments covering the fundamentals of browser automation with Selenium WebDriver and Python.
**📹 Each assignment includes a video walkthrough.**

- Multi-locator challenge (ID, NAME, XPATH)
- Explicit waits with `WebDriverWait`
- Checkboxes & autocomplete dropdowns
- JavaScript alerts, confirms, and prompts
- Web table data extraction
- Iframes & multiple browser tabs

### 🧪 Module 2 — Unit Test Frameworks
Three assignments that show how to structure Selenium tests into clean, reusable test suites.
**📸 Each assignment includes output screenshots.**

- Page Object Model (POM) restructure
- Data-Driven Testing (DDT) with CSV
- PyTest integration with HTML reporting and screenshots on failure

### 🥒 Module 3 — BDD API Automation
Three assignments built around Behavior-Driven Development (BDD) using Python and Selenium.
**📸 Each assignment includes output screenshots.**

- BDD flow setup with Given / When / Then
- Data-driven scenarios from JSON
- POM integrated into BDD-style test flow

### 🤖 Module 4 — Robot Framework
Two assignments covering the essentials of Robot Framework with real browser automation.
**📸 Each assignment includes output screenshots.**

- Basic syntax, variables, loops, assertions
- Custom Python keywords and BuiltIn library
- Suite setup/teardown, tags, and HTML reports
